# Shared packages
Cross-service interfaces and bootstrap; changes can affect every .NET service and the gateway.

- `Shared.PublicContracts/`: DTOs, events, question types and paper-wide normalization.
- `Shared.Grpc/Contracts/exam_internal.proto`: ExamInternal wire contract; generates both client and server types.
- Protobuf code is generated by `Grpc.Tools` during build (`GrpcServices="Both"`); edit the proto, not generated `obj/` output.
- `Shared.Bootstrap/`: auth, JSON, CORS, Swagger and Kestrel; `Shared.Security/`: roles/scopes/claims; `Shared.ServiceDefaults/`: telemetry/health/resilience.
- Prefer immutable boundary DTOs (`sealed record`/`readonly record struct`, `init`); preserve serialization and nullable compatibility.
- `QuestionType` contains shared string constants, not a numeric enum; preserve persisted/wire values.
- Question-type changes must cover exam delivery and attempt grader registrations; do not create migrations unless persisted schema changes.
- Trace all callers before altering shared auth defaults, events, DTOs or proto fields; retain wire compatibility and endpoint-specific internal policies.
- Build from root: `dotnet build Project_Langfens_Microservice.sln`; test affected consumers using their guides.
