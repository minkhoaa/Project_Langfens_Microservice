## 1. Overview & Separation of Corpora

This document defines the formal checklist for external human curators, the blinded human review workflow, and the cryptographic sealing procedure for the research freeze.

### Inviolable Corpus Separation Principle
1. **Confirmatory Judge Holdout ($N = 30$ questions):**
   - Purpose: Post-freeze evaluator reliability assessment (measuring post-freeze False Rejection Rate [FRR], False Acceptance Rate [FAR], and abstention rate; strictly forbidden for additional threshold tuning, parameter optimization, or heuristic calibration).
   - Stratum: 18 Reading questions (6 TRUE, 6 FALSE, 6 NOT GIVEN) and 12 Grammar MCQs (6 Mandative Subjunctive, 6 Reduced Participle Clauses).
   - Lifecycle: Curated by independent external panel, cryptographically sealed before unsealing.
2. **RQ2 Paired Experimental Corpus ($N = 25\text{--}40$ tasks per domain):**
   - Purpose: Direct hypothesis testing for Research Question 2 (Task decomposition across specialized agents vs. single-LLM direct vs. single-LLM self-review).
   - Units: 25–40 Reading passages (1–2 question groups each) and 25–40 Grammar rule sets evaluated across Arms A, B, and C ($N_{\text{total}} = 150\text{--}240$ assigned slots).
   - Lifecycle: Frozen experimental inputs evaluated during the confirmatory campaign.

## 2. Independent Curator's Dataset Checklist

The external panel curator must independently complete, sign, and verify each item in this checklist:

### Section A: Source Family Isolation & Provenance
- [ ] **Disjointness Audit:** Verify that holdout source texts originate strictly from the quarantined source families:
  - Reading: `fam-astrophysics-pulsar-08` (Pulsar Magnetospheres) and `fam-paleontology-cambrian-09` (Burgess Shale Taphonomy).
  - Grammar: `fam-mood-subjunctive-08` (Formal Legal Subjunctive) and `fam-aspect-participle-09` (Reduced Participle Clauses).
- [ ] **Source-Family Isolation & Leakage Checks:** Confirm complete source-family isolation from development families (`fam-botany-*`, `fam-oceanography-*`, `fam-syntax-inversion-dev-*`), and verify that items pass exact and near-duplicate leakage checks (e.g. 3-gram shingle Jaccard similarity < 0.3) against all development and calibration passages.
- [ ] **Documented Provenance:** Source documents must cite official academic textbooks, peer-reviewed monographs, or open-access repositories with verified licenses.
- [ ] **No Synthetic Data:** Attest that zero items or passages were generated by LLMs or automated synthetic pipelines. All holdout material must be curated from human-authored source texts.

### Section B: Reading Item Quota & Balance ($n = 18$)
- [ ] **Cardinality:** Exactly 18 items (9 per reading source family).
- [ ] **Balanced Distribution:**
  - 6 Strict Factual Entailment items (`TRUE`)
  - 6 Explicit Factual Contradiction items (`FALSE`)
  - 6 Unmentioned Topical Relation items (`NOT GIVEN`)
- [ ] **Citation Spans:** Each `TRUE` and `FALSE` item must have an exact verbatim citation span identified in the source text.
- [ ] **Length Bounds:** Reading passages must conform to the 720–915 word length bound.

### Section C: Grammar Item Quota & Quality ($n = 12$)
- [ ] **Cardinality:** Exactly 12 items:
  - 6 items: Mandative Subjunctive (`fam-mood-subjunctive-08`)
  - 6 items: Reduced Participle Clauses (`fam-aspect-participle-09`)
- [ ] **Defensibility:** Exactly 1 option must be standard academic English and grammatically defensible under descriptive and prescriptive grammars (e.g. Quirk et al., Huddleston & Pullum).
- [ ] **Distractor Defect Documentation:** Exactly 3 distractors per MCQ, each with an identified, non-ambiguous syntactic defect code (e.g. `INFLECTION_3RD_S`, `MODAL_PERFECT_DISCORD`, `DANGLING_PARTICIPLE`).

## 3. Blinded Human Review Workflow

To provide independent empirical validation without secondary AI model bias:

```
[Curated / Generated Items]
            │
            ▼
┌───────────────────────────────┐
│ 1. Blinding & Anonymization   │  • Assign random task_hrev_[a-f0-9]{12}
│    View Projection Layer      │  • Strip arm labels (A/B/C), prompts, scores
└──────────────┬────────────────┘  • Blind suggested answer key
               │
       ┌───────┴───────┐
       ▼               ▼
┌──────────────┐ ┌──────────────┐
│ Annotator 1  │ │ Annotator 2  │  • Independent 4-dimension scoring (1–5)
│ (Blind Key)  │ │ (Blind Key)  │  • Determine defensible key
└──────┬───────┘ └──────┬───────┘  • Assign binary PASS / FAIL
       │                │
       └───────┬────────┘
               ▼
┌───────────────────────────────┐
│ 2. Concordance & Inter-Rater  │  • Calculate Cohen's κ / Gwet's AC1
│    Reliability Analysis       │  • Identify discrepancies
└──────────────┬────────────────┘
               │
       ┌───────┴───────────────┐
       │ Agreement             │ Disagreement (Key or Pass/Fail)
       ▼                       ▼
┌──────────────┐       ┌───────────────────────────────┐
│ Consensus    │       │ 3. Adjudication by Panel Lead │
│ Certified    │       │    (Documented rationale)     │
└──────────────┘       └───────────────┬───────────────┘
                                       ▼
                               ┌──────────────┐
                               │ Final Human  │
                               │ Ground Truth │
                               └──────────────┘
```

### Reviewer Qualifications
- Official IELTS Academic Band 8.5+ or CEFR Level C2 certification.
- Minimum 3 years experience in English for Academic Purposes (EAP) assessment design.
- Minimum 90% concordance ($\kappa \ge 0.85$) on a 10-item calibration test.

### Review Rubric (4 Dimensions, 1–5 Scale)
1. **Source Grounding / Rule Conformance (1–5):** Factual support in text or grammatical conformance to rule.
2. **Answer Key Uniqueness (1–5):** Exactly one option defensible; no rival correct choices.
3. **Distractor Plausibility (1–5):** Realistically challenging to students while unambiguously flawed syntactically.
4. **Fluency & Clarity (1–5):** Standard academic IELTS register without ambiguity.

## 4. Reproducible Cryptographic Sealing Procedure

Once Section 2 checklist is complete, the curation panel lead executes the following reproducible sealing commands:

### Step 1: Package and Format Curated Artifacts
Organize curated items into canonical UTF-8 JSON files:
- `generation_baseline/holdout/reading_corpus.json`
- `generation_baseline/holdout/grammar_rule_packs.json`
- `generation_baseline/holdout/item_metadata.json`

### Step 2: Compute Cryptographic Hashes (SHA-256)
Compute deterministic SHA-256 digests on sorted, canonicalized JSON content:
```bash
python3 -c "
import hashlib, json

def canonical_sha256(path):
    with open(path, 'r', encoding='utf-8') as f:
        data = json.load(f)
    canonical = json.dumps(data, sort_keys=True, separators=(',', ':'), ensure_ascii=False).encode('utf-8')
    return hashlib.sha256(canonical).hexdigest()

print('Reading Corpus SHA256:', canonical_sha256('generation_baseline/holdout/reading_corpus.json'))
print('Grammar Packs SHA256 :', canonical_sha256('generation_baseline/holdout/grammar_rule_packs.json'))
"
```

### Step 3: Populate and Seal the Manifest
Edit `CONFIRMATORY_HOLDOUT_MANIFEST.json`:
1. Insert the computed SHA-256 hex strings for `reading_corpus_sha256` and `grammar_rule_packs_sha256`.
2. Compute `manifest_integrity_sha256` over the populated manifest content.
3. Update `status` to `"SEALED_UNINSPECTED"`.
4. Update `security_attestations` with the independent panel lead signature and timestamp.

### Step 4: Git Research Freeze Commit
Commit the sealed manifest and checklist with git cryptographic commit:
```bash
git add generation_baseline/research/CONFIRMATORY_HOLDOUT_MANIFEST.json
git commit -m "research(freeze): seal confirmatory holdout manifest with external panel attestation"
```
Once committed, the holdout package remains locked until campaign unsealing.
